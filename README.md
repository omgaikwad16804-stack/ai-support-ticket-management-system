# AI Support Ticket Management System

A beginner-friendly Python backend project with a small web dashboard. Create and manage customer support tickets, automatically classify them, assign a suggested priority, and generate a suggested customer reply.

## Features

- Create, search, and view support tickets
- Update ticket status and delete tickets
- Automatic category and priority suggestions
- AI-assisted summary and suggested reply (the current starter version uses a local rule-based baseline)
- SQLite database persistence
- REST API built with FastAPI
- Dashboard statistics
- Input validation and error handling
- API documentation generated by FastAPI

> **Honest project note:** This starter project does not call an external LLM yet. The analysis function is a local rule-based baseline so the app works without an API key. You can later add an LLM provider to make summaries and replies genuinely model-generated, and then update the README to describe that integration.

## Requirements

- Python 3.10 or newer
- pip

## Run locally

### Windows (PowerShell)

```powershell
cd ai_support_ticket_system
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

If PowerShell blocks activation, run this instead:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn main:app --reload
```

### macOS / Linux

```bash
cd ai_support_ticket_system
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Open **http://127.0.0.1:8000** for the dashboard.

Open **http://127.0.0.1:8000/docs** to try the REST API in Swagger UI.

The SQLite database (`tickets.db`) is created automatically on first run.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/health` | Health check |
| POST | `/api/tickets` | Create and analyze a ticket |
| GET | `/api/tickets` | List/search/filter tickets |
| GET | `/api/tickets/{ticket_id}` | Get one ticket |
| PATCH | `/api/tickets/{ticket_id}` | Update status, priority, or category |
| DELETE | `/api/tickets/{ticket_id}` | Delete a ticket |
| GET | `/api/stats` | Dashboard counts |
